The zip ties in these photos are load bearing. The carrier was designed for M3 thumbscrews,
but the printed clamps did not hold well enough, so the working mount is zip tied. That is
why the software has to measure how the glasses sit rather than assume it: the mount is not
repeatable between sessions, and a calibration that assumes a fixed seat expires the moment
the rig shifts.
